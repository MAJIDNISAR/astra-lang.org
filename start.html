Getting started

From clone to native binary
in five minutes.

Astra builds from source with the standard Rust toolchain. There is no installer to trust and no binary blob — you compile the compiler, then it compiles your programs.

Step 0Prerequisites

  • Rust (stable) — rustup recommended
  • LLVM tools — llc on your PATH (brew install llvm on macOS)
  • A C compiler — clang or gcc, for linking the small runtime

Primary tested platform is macOS ARM64. Linux works via the provided Docker setup (docker-compose up in the repo).

Step 1Build the compiler

$ git clone https://github.com/MAJIDNISAR/Astra.git
$ cd Astra
$ cargo build
$ cargo test --quiet     # 232 passed, 0 failed

Step 2Write and verify a program

hello.astra 
fn main() -> int {
    let name = "world";
    print("Hello, ${name}!");
    return 0;
}

verify typechecks without generating code — it's the fast feedback path, for humans and agents alike:

$ cargo run --bin astra -- verify hello.astra
Verification passed

$ cargo run --bin astra -- verify --error-format=json hello.astra
{"success": true, "diagnostics": []}

Step 3Compile and run natively

$ cargo run --bin astra -- compile hello.astra --output hello
$ ./hello
Hello, world!

The output is a real machine-code executable — no interpreter, no VM, no Python on the target machine.

Step 4Explore interactively

$ cargo run --bin astra -- repl
astra> let x = 21;
astra> print(x * 2);
42
astra> :quit

The REPL (alpha) accumulates your session and re-compiles the whole program on each entry — errors roll back cleanly. :help, :show, :reset, :quit.

Step 5Start a real project with Mifa

$ cargo run --bin mifa -- init myapp
$ cd myapp
$ cargo run --bin mifa -- verify
$ cargo run --bin mifa -- lock     # reproducible astra.lock
$ cargo run --bin mifa -- run

See the Mifa page for manifests, path dependencies, and the lockfile contract.
