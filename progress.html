Ignored-test burn-down

A release KPI: tests stay ignored until the feature truly works end-to-end, and the count must shrink every release. It is complete: 10 → 0 and has stayed at 0 since 2026-07-07. The end-to-end regression suite (tests/regression_tests.rs) has grown from 14 to 108 tests, each locking a shipped feature through compile → IR → native run → stdout/exit-code assertions. CI also gates every commit on cargo fmt, clippy -D warnings, cargo audit, and an llc IR-validity corpus.

Release testing v0.12

A black-box release suite tests the downloaded binaries, not the source tree: 55 checks covering 17 programs on the interpreter and native, modules, error codes and lines, astra fmt, astra fix and the Mifa flow. It runs on every platform before a release publishes, and a failure on any platform stops the release. v0.12.1-alpha scores 55/55 on macOS, Linux and Windows. v0.12.0-alpha's Windows run found that programs compiled but did not link there; v0.12.1 fixed it. v0.11.2-alpha scored 52/55 (mifa search failed).

From the first lexer to v0.12

Each release on one line, oldest first. Test counts are the suite at the time of the release.

  1. Oct 2025 v0.1

    The idea becomes code: a language as easy as Python, as safe and fast as Rust, built for agentic coding. Lexer, parser and the first AST.

  2. Nov 2025 v0.5

    Native compilation, Docker CI, first pre-built binaries.

  3. Jun 2026 v0.6 alpha

    Honest alpha reset: JSON diagnostics, verify mode, the AI-first verify-repair-compile loop.

  4. Jul 6, 2026 v0.7

    Source spans, structs / Result / closures native, REPL, dyn, ARC scaffolding, rich diagnostics with astra explain; Mifa lockfile and registry protocol.

  5. Jul 7, 2026 v0.8.0-alpha

    The true LLVM-IR backend becomes the default; async/await (synchronous lowering); ignored tests 10 → 0. 285 tests

  6. Jul 9, 2026 v0.9.0-alpha

    Soundness: nominal structs, enums with payloads, ? and try/catch, tuples, impl blocks, bitwise operators.

  7. Jul 15, 2026 v0.9.1-alpha

    First cross-platform binary release (Linux, macOS ×2, Windows); callable closures; ARC memory reclamation; the compiler never panics on malformed input. 449 tests

  8. Oct 30, 2026 v0.10.0-alpha

    Interpreter behind astra run with native parity and differential fuzzing; modules; program I/O with capabilities; runtime traps on both engines; mifa build / run. 609 tests

  9. Nov 2, 2026 v0.11.0-alpha

    Value semantics (structs and lists are values, mut parameters, E0022, a[i] = v), Python-style indentation and astra fmt, type inference, nominal traits and trait bounds with static dispatch. 695 tests

  10. Nov 2, 2026 v0.11.1-alpha

    Released binaries compile natively: the C runtime is embedded in the compiler, and macOS links for the compiler's own architecture. 699 tests

  11. Nov 2, 2026 v0.11.2-alpha

    Trait bounds checked at the call site and impl signatures checked against the trait (E0020); loops no longer leak memory (while bodies, list copies, struct list fields); every release binary is smoke-tested before publishing. 712 tests

  12. Nov 4, 2026 v0.12.0-alpha

    Every type error in the main file carries its line and column; machine-applicable fixes and astra fix; single-owner locals freed on every exit (a helper building a struct/list/tuple, called 1M times: 231 MB → 1.3 MB peak); bools print true/false; == only where it compares by value; mifa --version and an honest mifa search; a 55-check black-box release suite on every platform. 754 tests

  13. Nov 5, 2026 v0.12.1-alpha current

    Native builds on Windows; print and ${} refuse values that native code printed as heap addresses; xs.pop() refused until it returns an Option; the release check now blocks a release on any platform. 756 tests

  14. Next @derive and standard traits planned

    Fixes for E0021 and E0020; @derive(Eq) and trait default methods, then Show / Hash / Iterable; Map / Set and comprehensions; the remaining memory leaks; a WASI runtime build.

  15. v1.0 v1.0 planned

    GPU target, production tooling, hosted Mifa registry; the source opens at v1.0-beta.

Design investment, tracked like a feature

Astra's thesis is that when code generation is free, the strategic layer, the design investment Ousterhout says tactical programming skips, must live in the language and be enforced by the compiler. That claim is only honest if each piece of the strategic layer is tracked and tested like any other feature. This table is that commitment:

Strategic guaranteeMechanismStatus
Interfaces can't drift silentlyStatic types + inferenceshipped v0.6
Errors are values, not surprisesResult<T,E> + exhaustive match + ? operatorshipped v0.6 · ? v0.9
Feedback is a machine contractJSON diagnostics, stable E-codes, suggestion, astra explain; machine-applicable fix edits and astra fix (v0.12)shipped v0.7
Flexibility is explicit, never accidentaldyn gradual-typing boundaryshipped v0.7
Builds are reproducibleMifa sha256-stable astra.lockshipped M2
Memory correctness without generator burdenARC + escape analysis (no GC, no lifetimes)reclaiming since v0.9; every exit and owned strings since v0.12

Validated performance claims

Numbers on this site come from a scripted validation harness in the repo (scripts/validate_metrics.sh, 12/12 checks passing), not from marketing copy:

  • 115 ms: Astra compile and run of a 5M-iteration loop (Python: 959 ms run-only)
  • 113 ms: astra verify full typecheck of a program, no codegen
  • 4/4: classes of agent mistakes (undefined vars, type errors, arity, bad returns) rejected before execution
  • sha256-stable: astra.lock byte-identical across repeated resolutions

Ratified architecture decisions

Five foundational bets were debated and locked on 2026-07-02. They set the direction through v1.0 and can only change through a documented amendment process.

BetDecision
1, Memory modelARC + escape analysis + region (no GC, no borrow checker)
2, Typing disciplineStatic by default; gradual via explicit dyn boundaries
3, BackendOne LLVM compiler, three targets: native, WASM, GPU
4, AI primitivestool/agent/prompt/memory as language keywords
5, Python interopEmbedded CPython in the standard library
