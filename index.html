Verify,then run.

Astra is a compiled language for code that AI agents write: as easy to read as Python, as safe and fast as Rust. The compiler answers in JSON and repairs what it can before anything runs.

v0.13.2-alpha for Linux, macOS and Windows. 831 tests, none ignored.

Errors are data.

$ astra verify --error-format=json bad.astra
{
  "success": false,
  "diagnostics": [{
    "error_code": "E0002",
    "message": "Undefined variable 'totl';
                did you mean 'total'?",
    "line": 4, "column": 9,
    "fix": { "edits": [{
      "line": 4, "column": 9,
      "end_line": 4, "end_column": 13,
      "text": "total"
    }] }
  }]
}

astra verify Every error has a stable code, a line and a column, and a fix when the repair is certain.

$ astra build bad.astra -o sum && ./sum

astra fix Applies the edits and checks again. No model call for these errors. New in v0.12.

What ships next

One loop, no retries.

An agent writes code. Astra checks it, fixes what it can, and only then builds a native binary. The model is asked again only about what the compiler could not repair.

Astra is an alpha. The core language compiles and runs natively with every test green, but it is not yet a production language, a package ecosystem or a memory-safe systems language.

Planned: tool and agent keywords, Python interop, WASM and GPU targets, a hosted Mifa registry.
