v0.13.10-alpha is out.

Astra v0.13.10-alpha (2026-11-11) ships the astra compiler and the mifa package manager for Linux, macOS and Windows, and Astra as a WebAssembly module that runs wherever Node does. This alpha is an early-access preview: binaries go to testers through the private release page; public downloads will be published here.

Linux and Windows: v0.13.10 builds follow; meanwhile use v0.13.7-alpha on Linux and v0.13.6-alpha on Windows.

What's in the release

Each native download holds two programs, the compiler and the package manager; the WebAssembly download holds the compiler's front end and interpreter.

ItemWhat it is
astraThe compiler: astra build makes a native executable through LLVM; astra run runs a program instantly with the interpreter; astra verify type-checks and reports JSON diagnostics for agents
mifaThe package manager: create a project, depend on local packages, build and run
astra.wasmThe compiler's front end and interpreter as WebAssembly, with a JavaScript loader and a Node runner: node run.mjs prog.astra runs, checks, fixes and formats with no install; the engine of the playground
Showcase examplesSmall runnable programs, each one compiled, run and output-checked by the test suite

Building native executables needs the LLVM tools (llc) and a linker (clang on Linux and Windows, the Xcode Command Line Tools on macOS) on your PATH; astra run needs neither. The binaries are unsigned: on macOS run xattr -d com.apple.quarantine astra mifa; on Windows choose “More info → Run anyway”. The WebAssembly archive runs single-file programs (no import) and cannot build native executables. Compiling your program to WebAssembly is separate: astra compile f.astra --target=wasm32-wasi emits a wasm object, but there is no WASI runtime build yet to link it into a runnable .wasm.

Since v0.9.1

The main changes since v0.9.1:

  • Richer enums, patterns and generic structs (v0.13.10): Rect(float, float), Point { x: 0, y } / (0, y) / 0..=9 / | patterns, tail-expression returns, struct Stack<T> with impl<T>, language tour
  • @derive(Eq, Show) (v0.13.9): == and printing for structs, language tour
  • Python habits and trait default methods (v0.13.8): and / or / not / not in, single-quoted strings, trailing commas, if as a value, statements continued on the next line, unwrap / unwrap_or / is_some / is_ok, trait default methods, language tour
  • Linux fixes (v0.13.7): native builds link the C math library (a sqrt of a run-time value failed to link with v0.13.6-alpha on Linux), and every NaN prints as nan
  • elif, default arguments and sqrt (v0.13.6): elif in both syntaxes; parameters with literal default values that a call may leave off; sqrt for int or float, on both engines. A compound assignment such as shelf[find(k)].qty -= n runs its index once, language tour
  • Eight correctness fixes (v0.13.5): about 74 new probe programs, run on both engines, found them. Struct literals are typed by their name (two structs with the same fields no longer swap methods, and fields may come in any order); a range loop's end is evaluated once (wrong loop counts and a hang); xs.push(v) is type-checked; struct methods named push and to_string work; str results of trait methods in bound generics; [] struct fields keep their declared type; assignment evaluates the value first; xs[f()] += v runs f() once. No new language features. astra --version now reads the release's Cargo.toml, and the release build checks that tag, Cargo.toml and binaries agree
  • Calling C and a package registry (v0.13.3): extern "c" fn declares a C function (int, float, bool, str) and @link links its library; Mifa reads a static, self-hosted registry (a folder or any static web host) with mifa publish, mifa add <name>, mifa yank and mifa search, checksums pinned in the lockfile. There is no central public registry, Mifa page
  • Maps and sorting (v0.13.2): Map<K, V> with {k: v} literals, m[k], k in m, get and for k in m; list sort(), sort_by_key and reverse(); Result and Option carry any value. The eight real-world programs need no workarounds, language tour
  • Mifa git dependencies and workspaces (v0.13.2): dependencies by git tag, branch, commit or version, the whole graph solved, [workspace] members sharing one lockfile, Mifa page
  • String methods (v0.13.1): char_at, chars(), for c in s, starts_with, ends_with, replace, and < / > on strings, on both engines, language tour
  • Mifa version requirements (v0.13.1): Cargo's rules (^, ~, =, ranges) and the newest version by semver. Behaviour change: a bare "1.2.3" now means ^1.2.3; write "=1.2.3" to pin, Mifa page
  • Any AI agent can use Astra (v0.13): astra mcp is a Model Context Protocol server with verify, fix, run, build, format, explain and test; runtime errors carry stable codes (R0001–R0007), agents page
  • Astra in WebAssembly (v0.13): the release now includes astra.wasm with a Node runner, and the playground runs Astra in your browser
  • Three wrong answers fixed (v0.12.2): found by writing real programs, each checked against a Python version; see real programs
  • Native builds on Windows (v0.12.1): Windows compiles and links programs like macOS and Linux; install the full LLVM archive (the installer has no llc)
  • Machine-applicable fixes (v0.12): every type error carries its line and column, and astra fix repairs misspelt names and a missing or extra mut without a model call, agents page
  • Memory freed on every exit (v0.12): a helper called a million times peaks at 1.3 MB instead of 231 MB
  • Behaviour changes (v0.12): bools print true/false; == works only on numbers, bools and strings until @derive(Eq)
  • Nominal traits and trait bounds: trait Shape:, impl Shape for Circle:, fn total<T: Shape>(s: T) with static dispatch; E0020 names a missing or mismatched method, language tour
  • Loops no longer leak memory (v0.11.2): structs and lists allocated in for and while loops are freed every iteration
  • Value semantics: structs and lists are values; a function changes its caller's value only through mut parameters (E0022); a[i] = v
  • Multi-file programs: import util;, pub items, util::f() names, language tour
  • An interpreter behind astra run, tested for identical output against the native compiler
  • Program input and output: arguments, stdin, files and environment variables, with errors as values
  • Capabilities: deny file, network or environment access at build time; the compiler names the call chain that breaks the rule
  • Mifa builds and runs projects with local dependencies, Mifa page
  • Runtime safety: overflow, division by zero and out-of-bounds indexing stop with a clear error

The progress page tracks every feature and the test that backs it.
